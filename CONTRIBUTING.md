# Contributing

Keep this collection focused on workplace tasks, employee enablement, and job performance. Do not add school-oriented prompts, source exports, private content, or uninspected attachments.

For prompts, include purpose, use context, copy-ready instructions, input guidance, a fictional example, and quality checks. For skills, include YAML `name` and `description`, required inputs, actionable steps, outputs, examples, and checks. Keep source-backed requirements distinct from proposals.

Preserve factual meaning, attribution, permissions, obligations, and uncertainty. Never claim approval, installation, testing, or product capabilities without evidence. Do not invent policies, results, owners, dates, or commitments.

Add or revise `catalog.json`, the collection index, and `CATALOG.md` together. Keep links relative and resolvable. Run `python3 scripts/validate_library.py` before committing. Runtime tests, if performed later, must record the host, date, task, result, and limitations.
