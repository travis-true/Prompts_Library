# Deck types and narrative arcs

Select a structure that matches the communication job.

| Deck type | Useful arc | Close |
| --- | --- | --- |
| Training or enablement | Relevance → model → example → practice → feedback → application | Action, commitment, support |
| Executive decision | Context → stakes → evidence → options → recommendation → decision | Explicit decision and owner |
| Recommendation | Problem → causes → criteria → options → recommendation → implementation | Approval or next action |
| Change communication | Current state → why change → future state → impact → required action → support | What happens next |
| Technical briefing | Question → system/context → mechanism → evidence → limitations → implications | Understanding, decision, or risk |
| Project update | Objective → progress → evidence → risks → decisions → next period | Decisions and owners |
| Sales or proposal | Audience need → cost of status quo → approach → proof → fit → next step | Commitment or discovery |
| Workshop | Purpose → shared model → task → work cycle → review → decision/action | Owners and follow-through |
| Demonstration | Task → starting state → critical actions → result → checks → try it | Practice or next-use guidance |
| Reference | Organizing questions → structured answers → examples → lookup path | How to use the reference |

## Arc rules

- Do not force persuasion onto a neutral technical or reference deck.
- Use chronology, causality, learning progression, process, or decision flow when more appropriate than a problem-solution arc.
- Resolve the opening question or tension in the close.
- Use section dividers only when they orient the audience or mark a meaningful shift.
- Keep repeated recap slides only when complexity or duration makes them necessary.

## Duration and scope

Use duration to control scope, not to add visible timings automatically.

- Short presentation: one central idea and few supporting claims.
- Standard presentation: one coherent arc with selective evidence and examples.
- Long presentation or workshop: explicit sections, interaction, recaps, and breaks as needed.

If the required content cannot fit without sacrificing comprehension, reduce scope, split the experience, or move detail into notes or companion materials.
