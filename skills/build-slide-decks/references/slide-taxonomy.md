# Slide taxonomy

Use slide types as functional patterns, not fixed templates.

| Slide job | Primary purpose | Common visual treatment |
| --- | --- | --- |
| Title/opening | Establish subject, audience relevance, or question | Minimal title and one purposeful visual |
| Stakes/context | Explain why attention is needed | Image, concise evidence, or contrast |
| Outcome/agenda | Set useful expectations | Simple progression or short list |
| Claim | State and support one conclusion | Takeaway title plus evidence |
| Concept | Explain a model or principle | Visual metaphor, labeled illustration, or concise structure |
| Process | Show sequence and handoffs | Flow only when sequence benefits from visualization |
| Comparison | Reveal meaningful differences | Table, paired composition, or chart |
| Evidence/data | Interpret numeric or qualitative evidence | Chart, table, quote, or image with implication |
| Example/case | Ground an abstract idea | Scenario, before/after, artifact, or image |
| Demonstration | Orient to a live or recorded task | Setup, screen state, critical cues, fallback in notes |
| Activity/practice | Prompt learner or participant action | Clear task, time, resources, and success criteria |
| Debrief | Interpret experience against criteria | Questions, model answer, or evidence |
| Decision | Present options, criteria, recommendation, or approval | Decision table, tradeoff view, or recommendation |
| Risk/constraint | Make limitations and controls visible | Ranked risks, conditions, or control mapping |
| Roadmap/timeline | Show change over time | Milestones, phases, dependencies |
| Section transition | Mark a meaningful narrative shift | Short statement and deliberate visual change |
| Summary/synthesis | Connect the few essential conclusions | Integrated visual or concise synthesis |
| Action/close | Resolve the deck and specify next action | Decision, commitment, owner, support, or question |

## Slide specification

For each slide capture:

- `slide_id`
- `slide_job`
- `audience_takeaway`
- `title`
- `visible_copy`
- `evidence`
- `source_locator`
- `visual_concept`
- `layout`
- `speaker_notes`
- `interaction_or_transition`
- `accessibility`

## Selection rules

- Do not use a slide type because it is customary.
- Do not create a section divider for every minor topic.
- Do not use a diagram for a simple two-part relationship.
- Do not place a full procedure on one slide if the audience needs guided performance.
- Do not turn every concept into cards, panels, or icon grids.
- Use a blank or pause slide only when it serves delivery.
