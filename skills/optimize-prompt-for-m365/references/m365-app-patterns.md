# Microsoft 365 app patterns

Use only the section for the employee’s selected app. Treat current app Prompt Packs and available product knowledge as authoritative when they conflict with these general patterns.

## Copilot Chat

- Make the Source explicit through an attachment, pasted text, referenced file, page, meeting, or other accessible content.
- Request a self-contained response with clear headings, tables, bullets, or next steps appropriate to the task.
- State whether the response will be reused in an email, document, presentation, meeting, or plan.

## Word

- Identify the active, attached, or referenced document and any selected section.
- Specify document type, audience, headings, approximate length, tone, and required sections.
- Distinguish between drafting new content, revising selected content, summarizing a document, and preparing replacement text.

## Excel

- Identify the workbook, worksheet, table, named range, columns, or selected cells when known.
- Define the analysis question, relevant measures, filters, time period, expected calculations, and output format.
- Request formulas or explanations only when needed; require assumptions and missing-data issues to be stated.
- Prohibit invented values, categories, calculations, trends, or conclusions.

## PowerPoint

- Specify audience, presentation purpose, approximate slide count, narrative flow, tone, and desired visual treatment.
- Identify the source document, presentation, outline, or selected slides.
- Request slide titles, concise body content, suggested visuals, and speaker notes only when useful.
- Require claims, figures, and quotations to remain grounded in the supplied source.

## Outlook

- Identify the selected email, thread, attachment, meeting invitation, or supplied notes.
- Specify sender role, recipients, purpose, tone, length, required call to action, and deadline when known.
- Distinguish between drafting, replying, summarizing, extracting commitments, and preparing follow-up.
- Prohibit invented commitments, recipients, dates, decisions, or quoted statements.

## Teams

- Identify the meeting transcript, recap, chat, channel conversation, or pasted notes.
- Specify whether the output is a recap, announcement, reply, decision summary, or action list.
- For meeting content, request decisions, action items, owners, deadlines, risks, unresolved questions, and missing information as relevant.
- Distinguish confirmed statements from proposals or unresolved discussion.

## OneNote

- Identify the page, section, selected notes, or pasted material.
- Specify the note structure, headings, tags, summary, checklist, or follow-up items needed.
- Separate captured facts from interpretation and unanswered questions.

## Loop

- Identify the page or component and the collaborative purpose.
- Request concise, editable content such as a plan, agenda, decision log, task list, status table, or brainstorming structure.
- Define fields, owners, dates, status values, and update expectations only when supported.

## SharePoint

- Identify the source page, document, list, or supplied content.
- Specify the target audience, page purpose, headings, scannable structure, links, calls to action, and accessibility expectations.
- Do not imply publication or page modification unless supported; request publication-ready content when direct action is uncertain.

## Planner

- Identify the plan, workstream, source notes, or project information.
- Request task titles, descriptions, buckets, owners, start dates, due dates, priorities, dependencies, and checklist items only when supported.
- Label missing owners or dates instead of inventing them.

## Other Microsoft 365 app

- Use the app’s available Prompt Pack when present.
- Identify the source context, intended output, audience, structure, and constraints.
- Avoid unsupported capability claims; optimize for producing usable content inside or alongside the selected app.
