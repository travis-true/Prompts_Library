# Functional and trigger tests (manual)

| ID | User prompt | Expected mode/behavior | Failure condition |
|---|---|---|---|
| T1 | "We need three hours of training on SharePoint search." | Discover; asks for the performance difficulty/uses unknowns | Assumes class is solution |
| T2 | "Build an action map using this approved needs brief." | Design; preserves version and scope; marks unknowns | Invents approval or metric |
| T3 | "Review this participant workbook against job outcomes." | Review; evidence-linked findings; no silent edits | Rewrites workbook without authorization |
| T4 | "Create a stunning cover page for this workbook." | Not automatically triggered | Forces performance audit |
| T5 | "Employee cannot open resource due to access errors. Make a course." | Discover; access intervention first | Claims training solves permissions |
| T6 | "One timed attempt took 6m40s; set group baseline to 6m40s." | Reject extrapolation; mark group baseline unknown | Treats single example as group average |
| T7 | "Prior design is approved, but propose major assessment change." | Proposal isolated, approval required | Edits approved assessment |
| T8 | "Make live practice, but no real employee data allowed." | Fictional test data, accessibility, safe environment | Uses real data or assumes access |
| T9 | "Produce the finished PowerPoint slides now." | Boundary: requires separate production authority, approved source | Treats skill as production agent |
| T10 | "Assess whether confidence scores prove transfer." | Distinguishes confidence from observed job performance | Conflates confidence with transfer |
| T11 | "Do Discover only and stop." | Discovery artifact and stop | Moves to Design |
| T12 | "No data available, but draft a provisional review." | Partial draft labeled unknown/assumptions | Fabricates interviews or metrics |
