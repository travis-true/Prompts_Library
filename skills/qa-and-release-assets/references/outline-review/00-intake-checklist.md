# Review intake checklist

## Minimum review inputs

| Input | Status options | Review effect if missing |
|---|---|---|
| Outline to review | Available / Partial / Missing | Missing outline normally results in Not reviewable |
| Topic | Known / Inferred / Missing | Missing topic may limit source and scope review |
| Audience | Known / Inferred / Missing | Assess whether the missing audience materially changes the review |
| Desired performance or objectives | Known / Partial / Missing | Missing both is usually Major or Critical when no alignment can be established |
| Duration and breaks | Known / Partial / Missing | Timing becomes Not checked if it cannot be calculated |
| Delivery format | Known / Inferred / Missing | Limits activity, accessibility, and logistics review |
| User-supplied standards | Available / None / Unknown | Built-in review still proceeds |
| Source material | Available / Partial / Missing | May limit accuracy and higher-risk review |

## Useful context

- Expected enrollment
- Learner baseline
- Required topics
- Required delivery platform
- Existing facilitator or learner materials
- Assessment expectations
- Accessibility requirements
- Technology, permissions, and license constraints
- Required reviewers
- Intended development or delivery date

## Question threshold

Ask only when the answer would materially change:

- Severity
- Review disposition
- Interpretation of an outline element
- Timing validity
- Objective alignment
- Required review controls
- Revised structure

Otherwise, proceed and document the gap.

## Scope discipline
Identify review mode and artifact maturity. Missing context is not automatically a Major finding; determine whether it materially blocks a specific conclusion. Distinguish a readable partial outline from missing source material. Record scope-limited conclusions and the decisions needed for expansion.
