# Comparison and iteration

Set priorities before judging. Use a rubric as a decision aid, not a scientifically calibrated similarity metric.

| Criterion | Observable check |
| --- | --- |
| Identity and continuity | Visible traits, clothing, props, and states stay consistent |
| Action | Start/action/end sequence, direction, pace, and contacts match the brief |
| Camera and composition | Framing, subject size, screen direction, and camera movement fit |
| Timing and transitions | Key beats, cuts, and duration fit the target |
| Light and style | Lighting direction, contrast, palette, and visual language align |
| Audio and text | Requested words/cues synchronize; text is legible and correct |
| Task effectiveness | Intended audience can understand or use the result |

Mark each criterion Meets / Needs revision / Not inspected / Not applicable, with timestamped evidence. An optional numeric rating must have defined anchors; do not turn an impression into an unsupported accuracy percentage. Do not score audio from silent frames.

Keep successful instructions locked. Change one major variable per test when feasible. If several controls must change together, record the dependency; do not attribute causality confidently. Retain versions and seeds only when actually available. Stop at the user-defined budget or acceptance threshold; propose limits before further paid attempts if absent. Never continue paid runs automatically after a requested cap.

A comparison requires accessible reference and output media. Without output, return a test plan. Without the reference, assess only the supplied brief and disclose the narrower scope.
