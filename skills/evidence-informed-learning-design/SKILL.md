# Evidence-Informed Learning Design

Design the instruction and practice for an observable workplace task. If the work behavior or cause of a performance gap is still unclear, identify what needs to be resolved through performance analysis. If the request centers on sustained job use or business impact, use the practice evidence to inform a separate transfer or evaluation plan. Preserve approved objectives, criteria, and project constraints. Present proposed changes to approved materials for review when authorization is limited to review.

## Workflow

1. **Define the performance.** Identify who does what, under which conditions, with which tools or job aids, and to what standard. Use existing requirements where supplied. Ask one focused question if a missing detail would materially change the design. Otherwise state the assumptions that affect the output.
2. **Build the rationale.** Connect relevant learning research, evidence from the workplace, and professional judgment about the context. Look for the research claim’s source, outcome and fit. Treat stakeholder preferences as input on feasibility and learner experience. Identify gaps in local evidence and qualify what observations can support. For software training, establish whether the specified app, environment, and permissions are available when these affect practice.
3. **Choose and sequence practice.** For a complex skill, start with a representative end-to-end task at a manageable difficulty. Model it with a worked example that makes decision points visible. Move to a partially completed task or guided attempt. Reduce scaffolding as learners demonstrate readiness and use a fresh scenario for independent practice. For mixed experience, vary support while retaining the target performance. Use brief component drills if a recurring subskill limits performance on the whole task.
4. **Give feedback and plan reinforcement.** Tie feedback to the task standard, point out the specific gap, and give the learner a chance to apply the correction. Use delayed retrieval where learners need to recall a rule or decision, and delayed practice where they need to repeat a workflow. Mix similar cases once learners can handle each type and need to discriminate among them. For self-directed resources, add a short check learners can use to judge their result. Pick intervals and formats that fit the work.
5. **Specify evidence and revise.** Define what learners do, what the reviewer observes, and what counts as acceptable. Match allowed support to the assessment purpose and project criteria. Keep observed performance, confidence, completion, and later workplace use distinct. Report missing evidence as unobserved. Use performance patterns to decide what to reteach, simplify, or validate. Label hypothetical outcomes and pilot proposals clearly.

## Deliverable

For a design request, return a compact practice plan with the target performance, evidence rationale, practice sequence, feedback and retry, and performance check. Include reinforcement where it serves the objective. For a review, prioritize a few findings, each with the location or activity, the consequence for learning, the proposed change, and how to check the change. For a single activity, answer at that scale.
