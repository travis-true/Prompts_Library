# Demo environment manifest

| Item | Required state | Validation method | Reset method | Owner | Status |
|---|---|---|---|---|---|
| Product or process | [State] | [Check] | [Reset] | [Owner] | [Ready / Needs revision / Not checked] |

## Privacy check
- [ ] Notifications suppressed
- [ ] Unrelated windows closed
- [ ] Recent files and history inspected
- [ ] Fictional or approved data loaded
- [ ] Credentials, tokens, IDs, and personal data hidden
- [ ] Recording and screen-sharing boundaries confirmed


## Execution evidence and limits
Record version, actual reviewer/date/method/evidence and Not checked where unperformed. Record state preconditions, action side effects, verification before retry, Unknown outcome handling and bounded switch/stop budget as applicable. For assets record Planned / Created / Verified, actual location, source version and fallback equivalence/omissions. Preserve scene/action/source IDs. Do not infer readiness from a plan.
