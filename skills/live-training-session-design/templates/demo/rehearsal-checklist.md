# Demo rehearsal checklist

## Content
- [ ] Objective and takeaway are explicit
- [ ] Every scene supports the takeaway
- [ ] Narration matches visible actions
- [ ] Engagement checkpoints are timed
- [ ] Post-demo handoff is clear

## Environment
- [ ] Starting state validated
- [ ] Accounts, permissions, licenses, and dependencies checked
- [ ] Sample data loaded
- [ ] Notifications and private content controlled
- [ ] Reset tested

## Timing
- [ ] Standard version rehearsed
- [ ] Compressed version rehearsed
- [ ] Expanded options identified
- [ ] Compression and switch triggers understood

## Recovery
- [ ] Known failures tested where safe
- [ ] Alternate live path validated
- [ ] Backup assets opened successfully
- [ ] Presenter recovery language practiced

## Accessibility
- [ ] Important visuals are described
- [ ] Zoom and visibility are adequate
- [ ] Captions and audio are checked
- [ ] Keyboard or equivalent paths are ready
- [ ] Response alternatives are available


## Execution evidence and limits
Record version, actual reviewer/date/method/evidence and Not checked where unperformed. Record state preconditions, action side effects, verification before retry, Unknown outcome handling and bounded switch/stop budget as applicable. For assets record Planned / Created / Verified, actual location, source version and fallback equivalence/omissions. Preserve scene/action/source IDs. Do not infer readiness from a plan.
