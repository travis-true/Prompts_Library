# Write clear workplace messages — learner practice

**Version:** 1.1.0
**Release state:** Draft complete; review required

All scenarios and people are fictional. Use the response method the facilitator confirms. You may work independently instead of speaking or sharing with a peer. The facilitator must confirm an accessible response method before delivery.

## Five criteria

1. Purpose appears early.
2. Context is useful and concise.
3. Action is specific.
4. Ownership is clear.
5. Timing is clear.

## P-01 / A-01 — Diagnose

Message: “We talked about the onboarding guide and there are a few updates. Some sections may need work because things have changed. Can everyone take a look and let me know what you think?”

Name at least three supported issues and explain why one makes the message harder to act on. Do not invent missing details. The facilitator will provide feedback before the next task.

## P-02 / A-02 — Guided rewrite

Facts:

- Launch is Friday.
- Report testing problems by noon Thursday in the fictional Test Issues shared list.
- Include the affected task, observed result, expected result and impact.
- Morgan Chen reviews submissions Thursday afternoon.
- No fix or additional deadline is promised.

Starting message: “We are getting close to launch. If there are issues, we should probably know about them soon so they can be addressed. Please send anything you find.”

Rewrite with an early purpose, useful context and a specific action. Use the supplied owner, channel and timing; add no invented requirements. Check all five criteria and revise after feedback.

## P-03 / A-03 — Independent rewrite

Facts: Confirm the fictional move list by 2 p.m. Tuesday. Verify work location and equipment needs in the shared list. Jordan Lee consolidates corrections.

Starting message: “Reminder that the workspace move is happening and people have had questions. There is a list that needs to be checked. Please look at it and respond if something is wrong.”

Write your revision independently using only these facts. Each criterion is worth one point. To meet A-03, earn at least 4/5 AND meet C1 purpose, C3 specific action, C4 owner and C5 timing. An invented requirement fails the task regardless of score. Useful context is C2; it cannot compensate for a missing critical criterion.

## A-04 — Evaluate and explain

Mark each of C1–C5 Present or Missing in your own message. Explain one actual revision and how it helps the reader act. Both accurate ratings (E1) and a grounded explanation (E2) are required: 2/2. A facilitator must review your work before a verified result is recorded.

## If you need another attempt

Use targeted feedback to revise. The facilitator supplies an equivalent new scenario and applies the same criteria. Model responses stay separate until the corresponding attempt is complete.

## Transfer

Within two working days, use the criteria on one suitable work message; after seven days, self-check another. Share only a de-identified checklist and reflection through the confirmed support route. Do not submit confidential work messages. These follow-up arrangements are recommendations awaiting confirmation.
