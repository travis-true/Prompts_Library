# Activity and assessment guidance

## Activity selection

Choose an activity because it produces learning evidence, not merely variety.

For each activity, define:

- Placement in the course
- Objective supported
- Learner instructions
- Time limit
- Materials or tool
- Individual, pair, small-group, or full-group format
- Expected output
- Facilitator observation or feedback
- Debrief question
- Accessibility alternative
- Fast fallback

## Recommended live-learning techniques

- Guided practice
- Worked example completion
- Scenario sort
- Poll with rationale
- Think-pair-share
- Chat waterfall
- Whiteboard categorization
- Role play or simulation
- Case analysis
- Peer review using criteria
- Retrieval practice
- Teach-back
- Independent performance challenge

## Demonstration pattern

A useful demonstration should include:

1. Setup and goal
2. Starting state
3. Visible steps or reasoning
4. Common failure point
5. Recovery or correction
6. Finished result
7. Takeaway
8. Immediate learner practice

## Formative assessment

Use formative checks before errors compound. Include exact prompts where possible. A check must tell the facilitator what to do with the result.

## Final success check

The final check should require the learner to perform or decide, not merely state satisfaction. Define:

- Task
- Conditions
- Success criteria
- Evidence collected
- Feedback method
- Remediation or follow-up

## Virtual and in-person adaptation

Provide both versions when the delivery mode is unknown or hybrid. Do not assume every platform supports polls, breakout rooms, shared whiteboards, files, or reactions.

## Grounded scoring
Supply all practice facts before asking learners to act. Use stable objective/activity/assessment/criterion IDs. Include a facilitator-only model answer with annotations and acceptable alternatives. Make critical criteria mandatory regardless of total score. State the numeric threshold, feedback, remediation and equivalent retry. Do not infer individual success from a sample of class responses. For informal learning, label unobserved individual results as unknown; if completion requires demonstrated performance, collect and score each required response.
