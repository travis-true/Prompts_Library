# Accessibility and observation standards

- Describe meaningful visual actions aloud.
- Use caption-friendly language.
- Zoom or crop to the relevant area while preserving context.
- Keep cursor movement deliberate.
- Do not rely on color, sound, position, or gesture alone.
- Provide keyboard paths when relevant and verified.
- Provide an equivalent observation path through text, screenshots, or narration.
- Check that the audience can see the control, input, result, and status change.
- Provide instructions and checkpoints in text.
- Allow alternate response methods when response mode is not the objective.

Every scene must include an observation check: what learners must be able to see or hear to understand the takeaway.


Read [fallback equivalence](10-state-recovery-and-equivalence.md). Designed alternatives are not tested access. Record actual checks separately. Observation alternatives cannot establish omitted operation evidence.
