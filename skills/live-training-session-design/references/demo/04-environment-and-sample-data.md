# Environment and sample-data controls

## Environment manifest
Record:
- Product or process
- Platform and version
- Account or role
- License or entitlement
- Permissions
- Browser or operating system when material
- Dependencies and integrations
- Network requirements
- Starting state
- Reset state

## Sample data
Use fictional or approved values. Create one coherent scenario manifest with:
- People and roles
- Request or record
- Dates and times
- Files or attachments
- Task names
- Statuses
- Expected output

## Privacy and presentation controls
- Close unrelated windows.
- Disable or suppress notifications.
- Remove saved credentials and personal history from view.
- Use a clean demo profile when possible.
- Do not expose production secrets, tokens, IDs, or confidential records.
- Inspect browser tabs, bookmarks, recent files, and autofill.

## Reset controls
Document how to restore the starting state, remove created items, and prepare the next run.
