# Demo intake checklist

| Input | Why it matters | If missing |
|---|---|---|
| Workflow or topic | Defines demo scope | Ask if not inferable |
| Learner takeaway | Prevents feature tours | Create provisional takeaway and flag it |
| Audience level | Controls narration and pacing | Use neutral baseline and flag |
| Delivery mode | Controls visibility and interaction | Provide adaptable guidance |
| Duration | Controls scene scope | Recommend standard and variants |
| Product or process | Defines actions | Ask if ambiguous |
| Version and platform | Controls accuracy | Mark not verified |
| License and permissions | Controls feasibility | Add pre-demo check |
| Dependencies | Controls reliability | Include validation placeholder |
| Sample data | Controls realism and safety | Create fictional manifest |
| Privacy and risk | Controls safeguards | Apply conservative defaults |
| Backup assets | Controls recovery | Specify asset list to create |
| Sources | Controls authority | Label recommendations and verification |
