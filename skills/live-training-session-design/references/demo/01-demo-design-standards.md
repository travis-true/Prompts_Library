# Demo design standards

## Required design questions
- What should learners notice?
- What should learners understand?
- What should learners be able to do or decide afterward?
- What visible result proves the workflow worked?
- What can be omitted without losing the takeaway?

## Story arc
1. Problem and relevance
2. Starting state
3. Key decision
4. Demonstrated action
5. Visible result
6. Learner takeaway
7. Practice or application handoff

## Scope control
Classify content as:
- Required
- Optional enrichment
- Expert commentary
- Expanded-only
- Backup-only
- Out of scope

## Demonstration evidence
The demo should expose the reasoning, action, result, and criteria learners will need later. Merely showing that a feature exists is insufficient.
