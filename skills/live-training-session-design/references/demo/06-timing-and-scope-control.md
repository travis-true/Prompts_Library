# Timing and scope control

## Required variants
- Minimum viable version
- Standard version
- Expanded version

## Scene timing fields
- Planned minutes
- Compression savings
- Expansion allowance
- Non-negotiable action
- Compression trigger
- Expansion trigger

## Compression order
1. Remove optional enrichment
2. Remove expert commentary
3. Reduce examples
4. Use prepared result instead of secondary clicks
5. Skip optional scenes

Do not remove the visible result, learner takeaway, or necessary engagement checkpoint merely to save time.


Read [path timing rules](10-state-recovery-and-equivalence.md). Include checkpoint, transition, loading and recovery time within each scene budget. Each variant needs a dependency-safe action path and exact total; minimum duration is not universally five minutes.
