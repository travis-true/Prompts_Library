# Scene framework

Every scene must include:

- Scene ID and title
- Objective and purpose
- Learner takeaway
- Starting state
- Planned duration
- Minimum viable action
- Standard action
- Expanded action
- Required narration
- Optional enrichment
- Expert commentary
- Click path or process steps
- Audience checkpoint
- Expected visible result
- Failure indicators
- Recovery action
- Backup asset
- Accessibility and observation notes
- Transition

## Scene boundaries
Create a new scene when:
- The learning purpose changes
- The system state changes materially
- A new decision begins
- A recovery branch begins
- The presenter can safely shorten or skip the next segment

## Scene ID pattern
Use `DS-001`, `DS-002`, and so on. Reusable sub-scenes may use `DS-002A`.
