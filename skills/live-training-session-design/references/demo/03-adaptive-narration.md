# Adaptive narration guidance

## Required narration
Short language needed to explain purpose, action, result, and takeaway.

## Optional enrichment
Context, examples, analogies, or commentary that can be removed when time is tight.

## Expert commentary
Nuance for experienced audiences, edge cases, architecture, policy, or advanced implications. Use only when verified and relevant.

## Narration standards
- Synchronize words with visible action.
- State what changed and why it matters.
- Avoid describing every cursor movement.
- Pause before a critical click or decision.
- Use caption-friendly sentences.
- Avoid unnecessary idioms and unexplained jargon.
- State the takeaway at the end of each scene.

## Audience adaptation
For novice audiences, name interface regions and decision logic. For experienced audiences, compress basic orientation and add verified edge cases.
