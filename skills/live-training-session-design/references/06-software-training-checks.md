# Software training checks

Apply this file only when the course involves software, digital tools, or live system demonstrations.

## Environment record

Confirm or label unknown:

- Product and application name
- Platform: web, desktop, mobile, or mixed
- Operating system or browser when material
- Edition, version, or channel
- License or entitlement
- Tenant or administrator settings
- Required account and permissions
- Integrations and dependencies

## Feature classification

Classify each feature as:

- Available and verified
- Available but environment-dependent
- Licensed or permission-dependent
- Preview
- Announced or roadmap
- Retired or deprecated
- Not verified

Only verified, accessible features should anchor required hands-on practice.

## Practice data

- Use fictional or explicitly approved data.
- Do not require learners to expose private email, files, chats, customer records, health data, financial data, or confidential work.
- Provide one coherent practice scenario when possible.
- Include expected starting files, records, accounts, or sample content.

## Demonstration readiness

For every live demonstration, document:

- Required setup
- Starting screen or state
- Access test
- Primary click path or workflow
- Expected result
- Known failure points
- Recovery plan
- Backup screenshot, recording, or completed example
- What learners practice immediately afterward

## Pre-delivery technology check

Verify before delivery:

- Facilitator access
- Learner access
- Feature availability
- Sample content
- Sharing permissions
- Links
- Audio and video when used
- Polls, whiteboards, breakout rooms, or collaboration tools
- Backup assets

Unknown items must appear in the pre-delivery checklist and quality report.
