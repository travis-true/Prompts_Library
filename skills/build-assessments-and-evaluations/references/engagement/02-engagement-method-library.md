# Engagement method library

Select methods by learning purpose, not novelty.

## Activate prior knowledge

- Retrieval prompt
- Experience inventory
- Prediction poll
- Quick scenario choice
- Concept map

## Build relevance

- Consequence comparison
- Before-and-after example
- Short role-based case
- Error-spotting task

## Support comprehension

- Worked-example completion
- Pause and predict
- Categorization or sort
- Annotated demonstration
- Teach-back

## Support practice

- Guided exercise
- Pair problem-solving
- Simulation
- Role play
- Case analysis
- Tool-based sandbox
- Structured peer review

## Check understanding

- Poll with rationale
- One-minute response
- Error analysis
- Confidence plus evidence
- Scenario decision

## Re-engage or recover energy

- Fix the flawed example
- Rapid ranking
- Chat waterfall
- Micro-debate using criteria
- Silent reflection followed by choice

## Support transfer

- Action planning
- Job-context application
- Barrier planning
- Implementation intention
- Follow-up challenge

## Required activity fields

Every activity must state objective, placement, timing, learner action, evidence, facilitator response, accessibility path, fallback, and transition.
