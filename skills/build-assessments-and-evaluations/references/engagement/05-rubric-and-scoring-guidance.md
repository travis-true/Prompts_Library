# Rubric and scoring guidance

## Rubric types

### Analytic rubric
Use when separate criteria need individual feedback or diagnosis.

### Holistic rubric
Use when an overall judgment is appropriate and criteria interact strongly.

### Checklist
Use when required steps or elements are clear and equally necessary.

### Observation guide
Use during demonstrations, simulations, or role plays.

## Proficiency levels

Use neutral descriptive levels unless supplied standards require different labels:

- Exceeds the defined performance
- Meets the defined performance
- Partially meets the defined performance
- Does not yet meet the defined performance

Do not convert these into passing scores without an authorized decision.

## Rubric criteria

Criteria must:

- Map to objectives
- Be observable
- Avoid personality or protected-trait judgments
- Describe performance, not effort or intent
- Distinguish levels clearly
- Use examples when interpretation may vary

## Scoring reliability

For proficiency or high-stakes use, add:

- Rater guidance
- Anchor examples
- Calibration process
- Double-scoring or review rules when required
- Disagreement resolution
- Documentation requirements

## Decision integrity
Record standard ID/source/version, authorized decision owner, actual passing rule, critical criteria and evidence for any global proficiency classification. If absent, leave decision_rule null and report No proficiency decision. Do not invent a four-of-five rule in a map while the rubric says decision required. Preserve criterion-level observations; self-rating is not verified accuracy until compared with the actual artifact. A critical requirement must not be compensated by optional strengths when an authorized standard makes it mandatory.

## Keys and observation
Supply model responses with criterion annotations, acceptable alternatives, error feedback and equivalent new-fact retry. Provide separate learner and facilitator versions. Define per-learner collection/scoring and realistic workload. Sampled class responses cannot establish unreviewed learners' proficiency. Use anchors and a planned calibration/disagreement process; actual validation/calibration remain Not checked until performed.
