# Alignment and evidence standards

## Objective-to-evidence map

Every objective must map to:

- Required performance
- Learning evidence
- Engagement or practice
- Formative check
- Summative or proficiency evidence, when applicable
- Feedback
- Remediation
- Reinforcement
- Later evaluation, when required

## Evidence quality

Evidence should be:

- Directly related to the objective
- Observable
- Sufficient for the assessment stake
- Consistently interpretable
- Accessible through equivalent response paths
- Practical within the available time and environment

## Alignment status

- Aligned
- Partially aligned
- Not aligned
- Not reviewable

## Prohibited shortcuts

- Attendance is not evidence of skill.
- Satisfaction is not evidence of learning.
- Participation is not evidence unless the response demonstrates the objective.
- Completion is not proficiency without criteria.
- A quiz should not replace a performance task when the objective requires performance.

## Scope and accounting
Learning activities align to learning objectives. Reaction/evaluation measures align to evaluation questions and decisions; administrative/support elements state a purpose without masquerading as learning evidence. Map every asset to its parent agenda interval; embedded activity time is not added to the parent session total again. Preserve original objective IDs when revising assets.
