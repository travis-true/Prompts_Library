# Facilitator-only keys and observation guidance

**Version:** 1.1.0
**Release state:** Draft complete; review required

Keep this file separate from learner handouts during independent attempts. All responses below are model/anchor examples, not observed learner results. No aggregate passing score or qualification decision is authorized.

## ENG-001 / KC-001 / KC-002 / KC-003
- ENG-001: B is more actionable; accept a reason grounded in the explicit action, deadline or owner. An alternative interpretation must cite actual text, not invented intent.
- KC-001: B, Deadline; the request does not say when review is due.
- KC-002: B; it supplies review action, deadline and expected response. A selected option alone does not demonstrate message production.
- KC-003: Timing — “by 3 p.m. Thursday”; or ownership — “Casey Rivera will consolidate comments Friday morning”; accept any criterion accurately matched to Message B. An inaccurate criterion/quote pair needs correction.

## SCN-001 model
“Please report testing problems in the Test Issues list by noon Thursday so they can be reviewed before Friday’s launch. Include the affected task, observed result, expected result and impact. Morgan Chen will review submissions Thursday afternoon.”
Annotations: first sentence gives purpose, channel and deadline; second defines reportable information; third gives review ownership/timing. Accept different concise wording preserving these facts. Do not invent a guaranteed fix, extra owner, link or deadline. If a fact is omitted, return to the supplied fact sheet and revise that sentence.

## ASMT-001 model
“Please confirm your work location and equipment needs in the shared move list by 2 p.m. Tuesday. Jordan Lee will consolidate corrections for the workspace move.”
Annotations: the opening states the confirmation purpose, specific verification fields, location and deadline; the second sentence identifies the next owner and useful move context. No consolidation deadline or link is invented. Equivalent wording is acceptable. The message need not follow a fixed sentence count if facts and clarity are preserved.

## Descriptive criterion record
For each learner record Demonstrated / Not yet demonstrated / Not observed with the exact evidence. These are criterion observations, not a global pass/fail standard.

| ID | Criterion | Observable evidence / feedback |
| --- | --- | --- |
| C-01 | Purpose | Confirmation/review purpose appears early; move it earlier if buried |
| C-02 | Useful context | Context helps the recipient act; remove distracting background |
| C-03 | Action | Verify the specified fields in the supplied list; replace vague “look at it” |
| C-04 | Ownership | Jordan Lee consolidates corrections; distinguish recipient action and next owner |
| C-05 | Timing | Verification is due by 2 p.m. Tuesday; do not substitute consolidation timing |
| C-06 | Factual fidelity | Only supplied requirements appear; flag every invented requirement |
| C-07 | Self-evaluation | Ratings agree with the actual submitted message; self-report alone is unverified |
| C-08 | Rationale | One actual edit is explained using specific message evidence |

Action, owner, timing and factual fidelity are proposed critical review dimensions for future standard-setting. The owner must decide the approved performance/decision rule before any formal proficiency use. A strong total cannot erase an omitted essential requirement when a controlling standard makes it mandatory. This package supplies no such global rule.

## Feedback, retry and individual observation
Use criterion-specific feedback: “Add the supplied deadline”; “Name the verification fields”; “Remove the unsupported requirement”; “Match the self-rating to the sentence evidence.” Then use RETRY-001 with its new complete facts. No automatic progression or qualification follows a retry.

RETRY-001 model: “Please confirm your session choice and attendance mode in the Workshop Choices list by 10 a.m. Friday. Casey Patel will consolidate corrections Friday afternoon for the upcoming workshop.” Apply the same descriptive criteria, substituting supplied retry facts, and inspect the new self-check/rationale. Do not reveal this key before the independent retry attempt.

For the assumed 24 learners, collect one independent message/self-check/rationale from each. During the 17-minute activity the facilitator can sample for group feedback, but cannot infer every learner’s result from samples. Proposed later scoring allowance: 2 minutes per response × 24 = 48 facilitator minutes outside the session; actual feasibility is untested. Unreviewed responses remain Not observed. The owner must confirm collection/access, staffing, privacy arrangements, feedback timing and workload before delivery.
