# Workplace communication — learner practice

**Version:** 1.1.0
**Release state:** Draft complete; review required

All people, lists and deadlines are fictional. This example supports coaching practice only; it does not decide proficiency, certification, authorization or employment. Criteria are proposed practice guidance, not an approved passing standard. Do not invent missing requirements.

## Objective IDs
- O-01: Identify unclear purpose, missing context, vague action and absent timing in a message.
- O-02: Revise a message using supplied facts so purpose, action, ownership and timing are clear.
- O-03: Evaluate a message against criteria and explain an evidence-supported improvement.

## ENG-001 — Opening comparison
Message A: “Following up on the schedule. Please take a look and let me know.”
Message B: “Please review the revised schedule by 3 p.m. Thursday and comment on any conflict. Casey Rivera will consolidate comments Friday morning.”
Prompt: Which message is easier to act on? Select A or B and quote one phrase supporting your reason. Respond in writing or verbally; digital polling is optional. Keep the selected message and rationale together.

## KC-001 — Missing detail
Message: “Please review the schedule and let me know.”
Question: Which missing detail most directly prevents knowing when to act? A Purpose; B Deadline; C Tone; D Greeting. Give the choice and one reason. This recognition task is not evidence of independent message creation.

## KC-002 — Strongest revision
Choose the revision making action and timing clearest: A “The schedule has changed. Please take a look.” B “Please review the revised schedule by 3 p.m. Thursday and comment on any conflict.” C “There are many schedule concerns that need discussion.” D “FYI, the schedule is attached.” Explain the wording supporting your choice.

## KC-003 — Explain evidence
Use Message B from ENG-001. Name one criterion it meets and quote the exact phrase that supports your judgment. Another supported criterion is acceptable; no global passing score applies.

## SCN-001 — Guided rewrite
Facts: A Friday launch is approaching. Report testing problems by noon Thursday in the Test Issues list. Include the affected task, observed result, expected result and impact. Morgan Chen reviews submissions Thursday afternoon. No resolution promise is supplied.
Starting message: “We are getting close to launch. If there are issues, we should probably know about them soon. Please send anything you find.”
Task: Rewrite using only the supplied facts. Define the action, submission location, deadline and owner. Compare against purpose, useful context, action, ownership, timing and factual fidelity. Submit a message and identify one revision. You may work individually or in a pair for practice; no individual proficiency is inferred from a shared response.

## ASMT-001 — Independent performance practice
Facts: Confirm the workspace move list by 2 p.m. Tuesday. Employees verify work location and equipment needs in the shared list. Jordan Lee consolidates corrections. No consolidation deadline or link is supplied.
Starting message: “Reminder that the workspace move is happening and people have had questions. There is a list that needs to be checked. Please look at it and respond if something is wrong.”
Task: Revise the message, mark each criterion Demonstrated / Not yet demonstrated / Not observed, and explain one change using a phrase from your own revision. Criteria: purpose, useful context, specific action, ownership, timing, factual fidelity, accurate self-evaluation, grounded rationale. These are descriptive practice observations; no 4/5 rule, cut score or global proficiency judgment is authorized.

## RETRY-001 — New-fact retry after feedback
Facts: Confirm session choice and attendance mode in the Workshop Choices list by 10 a.m. Friday. Casey Patel consolidates corrections Friday afternoon.
Starting message: “The workshop is coming. Please check the details and let us know.”
Task: After targeted feedback, write a new message, self-check the same criteria and explain one revision. The facilitator provides the model answer only after you attempt the task. This follow-up is outside the 90-minute session and is scheduled only if needed.

## Participation and transfer
Use an editable document, a paper worksheet or another agreed accessible text-response method. The construct is message writing and evaluation; an oral response alone cannot prove independent writing unless the intended response standard is explicitly adapted and justified. Assistive technology or a scribe may preserve writing evidence when the learner controls the composed message; confirm arrangements. Actual format/platform access remains untested.

A follow-up practice task and timing are recommendations for the owner to select. Share only fictional or approved content. No work-message submission, individual learner result or later workplace outcome is asserted by this example.
