# Engagement and assessment package

**Version / release state / requested scope:**

1. Context, preserved source objectives/assets, intended decisions and stake clarification.
2. Objective/evidence map and changes with rationale.
3. Parent agenda with separate total/break/administration/instruction time.
4. Embedded/additional/follow-up placement and activity specifications.
5. Complete learner inputs and separate annotated facilitator keys.
6. Descriptive criteria or actual authorized standard; critical-error and decision limits.
7. Individual collection, scoring workload, rater anchors and calibration status.
8. Construct-preserving access/fallback records and actual testing limits.
9. Feedback, new-fact retry and proposed reinforcement.
10. Selected decision-led evaluation measures; unselected-level rationale.
11. Reusable asset metadata with source versions and review/owner status.
12. All twelve quality checks, actual validator result and open decisions.
13. Traceable production and actual-file QA handoffs.

A single-asset request uses only applicable sections; do not generate a competing whole course or mandatory four-level evaluation to fill a template.
