# Assessment asset

Record ID/version, title, objective IDs, source IDs/versions, type, difficulty, delivery, intended result use and stake clarification. Indicate single asset or package scope.

## Learner version
Supply actual prompt, complete facts/inputs, conditions, materials, time and expected output. Do not leak model answers during an independent attempt.

## Facilitator-only key
Supply annotated model, accepted alternatives, observable criteria, proposed critical-error observations, common errors, targeted feedback and new-fact retry. Link each criterion to objective and evidence.

## Scoring and decisions
Record the actual authorized standard, scope/version, decision owner and passing rule if supplied. Otherwise: No proficiency decision; report descriptive criterion observations only. Do not infer a global pass from a total, class sample or self-rating. Record unknown consequences and the clarification question before consequential scoring.

## Administration and access
State individual collection, scoring capacity/timing, rater anchors/calibration plan, primary route, fallback equivalence and actual verification limits. Include full asset metadata and open decisions.
