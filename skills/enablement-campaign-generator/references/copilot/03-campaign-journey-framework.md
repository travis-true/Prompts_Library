# Campaign journey framework

## Phases
1. Awareness: explain relevance and responsible-use baseline.
2. First wins: small, low-risk tasks that produce visible value.
3. Daily habits: repeatable prompts and review routines.
4. Workflow integration: connected multi-step work patterns.
5. Advanced practice: stronger grounding, refinement, comparison, and reusable prompts.
6. Advocacy: share validated wins and help peers.

For shorter campaigns, combine phases but preserve sequence. Use periodic retrieval, recap, challenge, and reflection instead of introducing a new capability every day.


Difficulty follows task demands, not phase names. Interleave new-fact retrieval/retry, cumulative work and repeat use; phase labels alone do not establish progression.
