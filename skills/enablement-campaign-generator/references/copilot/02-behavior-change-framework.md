# Behavior-change framework

## Path
Awareness -> first attempt -> successful result -> repeated use -> workflow habit -> peer sharing.

## Asset design
For each tip define:
- Current friction
- Target behavior
- Prompt or action
- Expected result
- Human review step
- Friction reducer
- Reinforcement
- Observable signal

## Measurement discipline
Views are exposure, not adoption. Reactions are engagement, not skill. Self-reported confidence is useful but not direct evidence of performance. Use several signals and state limitations.


Measure attempts separately from learning and adoption. Use [operational metric definitions](08-measurement-framework.md); repeated use needs an explicit period and evidence source.
