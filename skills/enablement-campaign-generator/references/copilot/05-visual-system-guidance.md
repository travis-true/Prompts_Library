# Neutral visual-system guidance

Use a simple, accessible visual family with no proprietary logos or colors. Maintain recurring composition, typography hierarchy, illustration or photography style, and campaign marker.

Every visual concept must include purpose, channel, aspect ratio, focal subject, composition, style, color approach, text treatment, image-generation prompt when needed, alt text, and accessibility note.

Generated-image prompts should avoid logos, private data, real employee likenesses, unsupported interface screenshots, and excessive embedded text. Label generated visuals for human review.


Alt text is provisional until checked against the rendered final visual. Specify dimensions/ratio, purpose and image-generation prompt; a brief is not a generated or accessible-tested image.
