# Prompt design and tip-to-action

Prompts should state a clear goal and add relevant context, sources, and expectations when useful. Include placeholders and do not imply access to sources the user has not supplied.

Each tip includes:
- Scenario
- Why it matters
- Prompt
- Action today
- Expected outcome
- Review and verification step
- Responsible-use note when relevant
- Variation or reinforcement

Do not present prompt wording as a guarantee. Encourage refinement and human review.


Use Goal → Context → Source → Expectation for reusable examples. Supply complete fictional inputs and a filled example; distinguish illustrative model output from observed product output. Generated review cannot replace source verification.
