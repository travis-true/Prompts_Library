# Campaign intake checklist

| Input | Why it matters | If missing |
|---|---|---|
| Goal and business need | Sets campaign outcome | Propose and label |
| Audience and maturity | Controls difficulty and tone | Use mixed-experience baseline |
| Behavior targets | Enables measurement | Propose observable behaviors |
| Cadence and duration | Controls volume | Recommend flexible journey |
| Channels | Controls adaptations | Use multi-channel default |
| Copilot experiences and licenses | Controls valid claims | Mark unknown and verify |
| Approved policies and tools | Controls responsible use | Add release blocker |
| Brand or visual system | Controls visuals | Use neutral system |
| Review and publishing owners | Controls governance | Add placeholders and block release |
| Support route | Gives help path | Add placeholder |
| Measurement access | Controls dashboard | Separate available and desired signals |
| Existing assets | Enables reuse | Inventory when supplied |
