# Fifteen-check quality report

Record Q-01–Q-15 individually using [governance definitions](../../references/copilot/09-library-and-governance.md). For each: ID, title, applicability/rationale, required flag, scope, Pass / Needs revision / Not checked / Not applicable, artifact version, actual method, evidence locator/quote, reviewer/date, corrective action and owner. Planned checks cannot Pass; exclusions need rationale and cannot count as Pass.
