# Training asset catalog

Use this catalog to select assets by function. Do not treat it as a required bundle.

## Point-of-need performance support

| Asset | Best fit | Avoid when |
| --- | --- | --- |
| SOP or procedure | Controlled, repeatable process requiring authoritative steps | The workflow is not approved or stable |
| Task QRG or job aid | Concise steps used during work | The task requires substantial judgment without examples |
| Workflow guide | Multi-step work with handoffs or stages | A single short checklist is sufficient |
| Decision guide or decision tree | Users must choose among defined paths | Decision rules are unsupported or highly individualized |
| Checklist | Omission prevention or completion verification | Users still need instruction in how to perform the work |
| Troubleshooting guide | Known symptoms, causes, fixes, and escalation | Causes and resolutions are not validated |
| Comparison guide | Selecting among tools, options, or approaches | The comparison criteria are subjective or unstable |
| Reference card or cheat sheet | Frequent lookup of stable commands, terms, or syntax | Context and explanation are essential |
| Prompt guide | Repeatable AI-supported task with review and safety controls | The underlying workflow or permitted data use is unclear |
| FAQ | Recurring questions with authoritative answers | Users primarily need procedural steps |
| Task map | Shows where work happens across tools or stages | Detailed execution steps are the primary need |

## Live learning

| Asset | Best fit |
| --- | --- |
| Session plan | Defines objectives, flow, timing, methods, roles, and contingencies |
| Slide deck | Supports explanation, demonstration, discussion, and visual orientation |
| Facilitator guide | Enables consistent delivery, timing, prompts, debriefs, and recovery |
| Participant workbook | Combines guided notes, practice, reflection, and durable reference |
| Demonstration plan | Specifies realistic setup, actions, narration, and fallback |
| Practice activity | Lets learners perform the target behavior with feedback |
| Scenario or case | Develops judgment, application, and decision quality |
| Follow-up resource | Supports transfer after the event |

Do not recommend slides as the sole asset when learners must perform a task.

## Self-paced and digital learning

| Asset | Best fit |
| --- | --- |
| eLearning module | Consistent instruction at scale with interaction or tracking |
| Microlearning lesson | One narrow behavior, concept, or reinforcement need |
| Interactive tutorial | Guided software or process practice |
| Simulation | Safe practice for complex, high-risk, or judgment-heavy work |
| Demonstration video | Observable procedure, interface, or modeled behavior |
| Explainer video | Concise conceptual or change explanation |
| Audio lesson | Listening-friendly reinforcement where visuals are unnecessary |

Provide equivalent access through captions, transcripts, descriptions, keyboard operation, and alternative formats as applicable.

## Communication and adoption

| Asset | Best fit |
| --- | --- |
| Announcement or launch message | What is changing, why, when, and required action |
| Teams or social post | Short awareness, tip, reminder, or call to action |
| Email series | Sequenced launch, reinforcement, or behavior campaign |
| Infographic or visual card | Scan-friendly concept, comparison, or reminder |
| Manager toolkit | Talking points, reinforcement prompts, FAQs, and escalation |
| Office-hours plan | Time-bound support for adoption or difficult transitions |
| Adoption campaign | Coordinated multi-channel behavior reinforcement |

Communication creates awareness; it does not substitute for practice when skill is required.

## Assessment and evaluation

| Asset | Decision supported |
| --- | --- |
| Diagnostic or pre-assessment | What learners already know or can do |
| Formative knowledge check | Whether instruction should continue or adapt |
| Post-assessment | Whether defined knowledge or skill was acquired |
| Practical or skills assessment | Whether the task can be performed |
| Observation checklist | Whether behavior meets explicit criteria |
| Confidence check | Perceived readiness; never substitute for performance evidence |
| Session evaluation | Whether delivery and materials supported learning |
| Follow-up survey or interview | Whether transfer, barriers, or support needs changed |
| Operational metric | Whether workplace performance changed |

Do not add an assessment without a defined decision owner and intended use.

## Operational and production support

- content outline or design brief;
- source inventory and authority map;
- accessibility plan;
- brand and template specification;
- caption, transcript, alt-text, and description package;
- publishing and distribution plan;
- support and escalation record;
- ownership, version, review, and maintenance record;
- QA checklist, defect log, approval record, and release package.

Recommend these only when needed to build, govern, release, or maintain the learner-facing assets.
