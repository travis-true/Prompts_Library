# Validation test cases

Use these cases to verify routing behavior. Evaluate whether the skill reaches the expected decision pattern without copying the wording below.

## Case 1: Existing deck, missing transfer support

**Request:** A 60-minute virtual software session already has an approved slide deck. Recommend supporting materials for new employees who must use the workflow independently.

**Expected behavior:** Preserve the suitable deck; recommend facilitator support, guided and independent practice, a durable task reference, and only purposeful measurement. Do not recommend rebuilding every asset.

## Case 2: Infrequent stable task

**Request:** Employees perform a seven-step administrative task about twice per year. Errors are low consequence.

**Expected behavior:** Prioritize a concise point-of-need job aid or checklist. Do not default to a course or live session.

## Case 3: High-judgment work

**Request:** Supervisors must decide how to respond to ambiguous employee scenarios with material consequences.

**Expected behavior:** Recommend authoritative decision support, realistic scenarios, facilitated debrief or coaching, performance-based assessment, escalation, and controlled maintenance.

## Case 4: Non-training cause

**Request:** Employees know the process but cannot complete it because permissions are missing.

**Expected behavior:** Route the primary response to access remediation. Recommend communication or troubleshooting only if it helps users recognize and escalate the problem.

## Case 5: Awareness campaign

**Request:** Announce a minor interface change that does not alter the underlying workflow.

**Expected behavior:** Recommend a concise change message or visual, update the existing reference if affected, and avoid formal training.

## Case 6: Software rollout

**Request:** A new enterprise tool affects several roles with different tasks and mixed experience.

**Expected behavior:** Recommend a shared orientation only where useful, role-based learning and task support, troubleshooting, manager reinforcement, accessible delivery, and targeted adoption evidence.

## Case 7: Unsupported high-risk content

**Request:** Create a mandatory procedure package from informal notes that conflict with policy.

**Expected behavior:** Stop content production. Require authoritative reconciliation and accountable approval; provide only a provisional package recommendation.

## Case 8: User requests every asset

**Request:** Build a deck, workbook, facilitator guide, QRG, video, eLearning, assessment, infographic, email series, and manager toolkit for a simple five-minute task.

**Expected behavior:** Challenge unnecessary scope, recommend the smallest effective package, and classify excluded assets as not recommended with reasons.

## Case 9: Immediate answer with missing context

**Request:** Recommend assets now; do not ask questions. Only a broad topic and audience are supplied.

**Expected behavior:** Provide a provisional recommendation, label assumptions and gaps, lower the confidence level, and identify decisions that could change the route.

## Case 10: Production requested after routing

**Request:** Recommend the package and then create the approved job aid.

**Expected behavior:** Complete and present the route first. Build only the authorized asset using the relevant creation skill and supplied sources.

## Blocking failures

The skill fails validation if it:

- recommends training without diagnosing the cause;
- creates assets during recommendation-only mode;
- invents source facts, approval, policy, roles, system behavior, or effectiveness;
- recommends every available asset without distinct justification;
- omits point-of-need support for detailed infrequent work;
- uses awareness communication as a substitute for required practice;
- adds assessment without a decision purpose;
- ignores accessibility, risk, classification, ownership, or maintenance constraints;
- presents a high-confidence route when decisive evidence is absent;
- continues high-risk content production despite conflicting or unauthoritative sources.
