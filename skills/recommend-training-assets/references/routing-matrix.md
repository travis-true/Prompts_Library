# Routing matrix

## 1. Cause-to-intervention routing

| Dominant cause | Primary response | Possible supporting assets |
| --- | --- | --- |
| Missing knowledge | Instruction or concise reference | Explainer, QRG, knowledge check |
| Missing skill | Demonstration, practice, and feedback | Session, tutorial, simulation, job aid |
| Memory or retrieval burden | Point-of-need support | Checklist, QRG, task map, searchable FAQ |
| Judgment or decision difficulty | Scenarios and decision support | Decision guide, debrief, practical assessment |
| Awareness gap | Communication | Announcement, campaign, FAQ, manager toolkit |
| Motivation or incentive | Management or performance-system action | Communication clarifying expectations |
| Process or policy defect | Process or policy correction | Updated SOP, change communication |
| Tool or access failure | Technical or access remediation | Troubleshooting and support guidance |
| Capacity or environment | Operational intervention | Reference or training only for the learnable portion |
| Mixed | Blended response | Route each confirmed cause separately |

## 2. Moment-of-need routing

| Moment | Preferred form |
| --- | --- |
| Before first performance | Orientation, instruction, modeling, safe practice |
| During performance | Searchable, concise, stepwise or decision-based support |
| After error or failure | Troubleshooting, feedback, coaching, targeted remediation |
| During change adoption | Communication, manager reinforcement, task support, office hours |
| Ongoing mastery | Advanced scenarios, community practice, coaching, spaced reinforcement |

## 3. Complexity and consequence

| Profile | Route |
| --- | --- |
| Low complexity + low consequence | One concise reference or communication |
| High complexity + low consequence | Demonstration plus job aid; optional practice |
| Low complexity + high consequence | Controlled checklist, approval, verification, and audit evidence |
| High complexity + high consequence | Formal learning, realistic practice, performance assessment, controlled support, human authorization, and maintenance |

## 4. Frequency

- Frequent and stable: build fluency, then provide a lightweight reference.
- Infrequent and stable: emphasize point-of-need support over memorization.
- Frequent and changing: use maintainable digital support and short update learning.
- Infrequent and changing: use authoritative retrieval, decision support, and escalation.

## 5. Audience and scale

- One role with common tasks: role-specific package.
- Multiple roles with different decisions: shared core plus role-based routes.
- Mixed experience: optional foundations plus direct access to task support and advanced practice.
- Distributed audience: self-paced or repeatable live delivery with facilitator controls.
- Accessibility or technology constraints: provide equivalent formats and avoid a single-channel dependency.

## 6. Package sizing

### Minimum package

Use when the need is narrow, low-risk, stable, and well supported. Include one primary asset and any mandatory accessibility or operational component.

### Standard package

Use when learners need explanation plus application. Include a primary learning experience, practice, a durable reference, and targeted reinforcement or measurement.

### Controlled package

Use for high-risk, regulated, high-consequence, or highly variable work. Add authoritative sources, role and approval controls, performance verification, versioning, support, maintenance, and release evidence.

## 7. Stop conditions

Pause routing or content production when:

- no desired workplace behavior or decision can be identified;
- authoritative sources are missing for high-risk content;
- sources conflict on required steps, roles, policy, or system behavior;
- the requested asset cannot address the dominant cause;
- information classification or permitted use is unresolved;
- required accessibility or delivery constraints make the proposed format unusable;
- the user requests a validation or approval claim without evidence.

Return the blocker, its consequence, the smallest action needed to resolve it, and any safe provisional recommendation.
