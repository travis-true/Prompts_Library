# Minimum Effective Training Package

## Purpose

Select and plan the smallest coordinated set of resources needed to support a workplace behavior.

Primary audience: Workplace.

## When to use it

Use when a new process, tool, or recurring task needs support and the appropriate asset mix is unclear.

## Inputs and requirements

Performance need; audience; evidence of barriers; use frequency; channels; capacity and constraints.

A supported skill host; access to supplied text/files. No bundled scripts or external services.

## Workflow guide

1. Define the desired work behavior, audience, current barrier, frequency, consequences, and observable success evidence. Separate evidence from assumptions. If the barrier is primarily access or process, include remediation rather than treating content as the solution.
2. Identify which needs actually apply: awareness, task reference, demonstration, practice/feedback, durable troubleshooting, manager support, or reinforcement. Do not require an asset for every category.
3. Compare candidate formats such as a short message, job aid, demo, practice task, help article, FAQ, or live session. Use the work context, task complexity, error consequences, available channels, and maintenance effort to decide.
4. Recommend the smallest set covering the supported needs. For each included asset state its audience, use moment, purpose, source, and expected behavior. Explain exclusions and when a deferred asset would become worthwhile.
5. Build a production table: asset, priority, dependency, owner, channel, effort estimate, due date, and review criteria. Label estimates; do not invent owners, deadlines, approved channels, or budget.
6. Specify checks for source accuracy, accessibility, usability at the point of work, cross-asset consistency, and maintainability. Reuse an existing resource when it meets the need.
7. Plan a small pilot and reinforcement linked to observed errors or questions. Distinguish completion/satisfaction from behavior and work outcomes. Define a review trigger for revising, adding, or retiring assets.
8. Return the barrier map, selected/deferred assets with rationale, production table, pilot/measurement plan, and unresolved decisions. Do not create all listed assets or publish anything unless the user requests that work.

Expected outputs: Barrier map, asset selection rationale, production plan, quality checks, reinforcement, and measurement plan.

### Start a request

```txt
Use Minimum Effective Training Package and its workflow for this task.
performance_need: [performance_need]
audience: [audience]
evidence: [evidence]
constraints: [constraints]
Ask one focused question at a time only if a material input is missing.
```

## Customize before running

- `[performance_need]`: Behavior and consequence Example: Coordinators omit a routing field, causing reassignment.
- `[audience]`: Who performs the task and where Example: 30 coordinators in a help-center queue.
- `[evidence]`: Examples or observations supporting the barrier Example: De-identified requests and a current procedure.
- `[constraints]`: Capacity, channels, timing, maintenance Example: Four creation hours; intranet and team messages.

## Example use and output

Fictional input: Thirty coordinators already know the process but cannot find the routing rules quickly. Four creation hours are available.

| Asset | Decision | Reason | Proposed effort |
| --- | --- | --- | --- |
| Routing job aid | Build first | Supplies the missing point-of-work reference. | 2 hours |
| Short launch message | Include | Shows where to find the job aid. | 0.5 hour |
| Two practice scenarios | Include | Checks correct routing with feedback. | 1 hour |
| Full course | Defer | Evidence points to information access, not a broad skill gap. | Not allocated |

Reserve 0.5 hour for review. Pilot with a small representative group; compare routing errors in comparable samples before and after use. Estimates and measurement design require owner confirmation.

## Check before using

Each asset addresses a supported barrier; exclusions are explained; effort fits capacity; source and owner gaps are visible; measurement includes behavior, not just attendance.
