# Using the skills

Every skill folder contains a readable `SKILL.md` with a name, a trigger description, required inputs, workflow, examples, and quality checks. Review it before use.

## Portable use

Open a skill file, paste the relevant workflow and your completed request into an assistant, and supply the sources it needs. A text assistant cannot perform image edits, browse, recalculate workbooks, or create files unless those tools are available.

## Hosts that accept skill folders

Use your host's supported skill-import mechanism with the individual folder. For a host requiring ZIP import, create a ZIP containing that one folder with `SKILL.md` at its root inside the folder. For a host reading skill directories, copy the individual folder into its supported skills directory. No skills were installed in your account by this migration.

These files were reconstructed from Notion's written workflow guides. The original platform ZIP attachments were not transferred or inspected. Do not assume they are byte-identical to those attachments. This edition bundles no scripts, tools, or binary assets. Internal related-resource links work in the full repository; retain repository context when using those links.

Repository checks validate frontmatter, files, links, catalog consistency, and workplace-only scope. They do not establish runtime compatibility or output quality in any platform.
