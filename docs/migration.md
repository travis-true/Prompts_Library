Superseded source records remain in Notion; current consolidated resources were migrated rather than duplicating obsolete content. The source's historical counts were not used as the current inventory.

This repository therefore contains the full written workflows, not byte-preserved copies of the old packages. No bundled scripts or binary assets are claimed. Source attachment links and platform-specific ZIP-installation claims were removed in favor of repository-based guidance.

## Source preservation

Notion originals remain intact. No pages were deleted, archived, or stripped of content. No raw export, source database properties, private identifiers, or superseded source copies were committed. This migration creates the workplace repository without destroying the recoverable originals.

## Validation

Run `python3 scripts/validate_library.py` for catalog totals, paths, required prompt sections, skill frontmatter, local links, unresolved Notion syntax, and residual school-context vocabulary. Content review additionally checks that converted scenarios serve employee work and preserve source-grounding and uncertainty safeguards.

Structural validation does not establish installation, runtime compatibility, accessibility conformance, or effectiveness across tools. Examples remain fictional and runtime tests have not been performed.
