# AI Enablement Planning Checklist

**Audience:** Workplace

> Use this checklist to turn an AI idea into a focused, supportable enablement plan.


## 1. Define the work problem

- [ ] Name the task or performance problem.
- [ ] Identify who performs the work.
- [ ] Describe what “better” looks like.
- [ ] Confirm that training or enablement can influence the result.

## 2. Choose the smallest useful intervention

- [ ] Decide whether the need calls for a prompt, job aid, demonstration, practice activity, course, or workflow change.
- [ ] Start with one high-value use case.
- [ ] Define what people should do differently after using the resource.

## 3. Set safe-use boundaries

- [ ] Identify approved tools and information sources.
- [ ] State what information must not be entered.
- [ ] Require people to verify important outputs.
- [ ] Keep a human decision-maker accountable for final work.

## 4. Plan adoption

- [ ] Provide a realistic example.
- [ ] Let people practice with their own work.
- [ ] Make support and troubleshooting easy to find.
- [ ] Reinforce the new habit after launch.

## 5. Measure usefulness

- [ ] Select one behavior measure.
- [ ] Select one work-result measure.
- [ ] Capture questions, errors, and support requests.
- [ ] Decide when the resource will be revised, expanded, or retired.
