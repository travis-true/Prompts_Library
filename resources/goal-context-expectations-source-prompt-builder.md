# Goal–Context–Expectations–Source Prompt Builder

**Audience:** Workplace

> **Four parts. Better answer.** Replace each bracketed field, then paste the completed prompt into your approved AI tool.


## Prompt builder


**Goal**  


I need you to \[state the job to perform\].


**Context**  


This is for \[audience, situation, purpose, and relevant background\].


**Expectations**  


Return \[format, length, tone, required sections, and quality criteria\].


**Source**  


Use only \[attached file, selected text, approved website, or named source\]. If the source does not support a claim, flag the gap instead of guessing.

## Copy-ready template

```txt
Goal: I need you to [job].

Context: This is for [audience and situation]. The purpose is [purpose]. Relevant background: [background].

Expectations: Return [format]. Keep it [length and tone]. Include [requirements]. Before finishing, check [quality criteria].

Source: Use only [source]. Identify missing or unsupported information.
```

## Quick quality check

- [ ] The goal starts with a clear action.
- [ ] The context explains who, why, and what matters.
- [ ] The expectations define the shape of the answer.
- [ ] The source tells the tool what evidence to use.
- [ ] Sensitive or restricted information has been removed.
