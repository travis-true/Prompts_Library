# Minimum viable training package

**Audience:** Workplace

> Build enough support for people to understand, try, use, and sustain the new behavior—without creating unnecessary content.


## 1. Define the outcome

- Name the work behavior that must change.
- Identify the audience, work context, and performance gap.
- Define one observable success measure.
- Check whether the barrier is knowledge, practice, information access, process, or tool access. Include remediation when content alone will not solve it.

## 2. Select the package

Select only what the evidence requires across awareness, performance support, practice, and reinforcement. Reuse suitable existing resources. These are options, not a mandatory production list:

- Announcement or launch message
- Quick-reference guide or job aid
- Demonstration video or live demo
- Knowledge article or reference page
- Practice activity
- Manager talking points
- FAQ

For each selected asset, record its purpose, audience, use moment, source, owner, channel, dependencies, effort, and review criteria. Mark unconfirmed owners and dates. Explain what is deferred and what evidence would justify adding it.

## 3. Build from authoritative sources

- Use current, approved source material.
- Keep the content outcome-based, role-aware, plain-language, accessible, scan-friendly, and maintainable.
- Separate facts from assumptions and unresolved questions.

## 4. Quality check

- Verify task accuracy and source alignment.
- Test accessibility, links, examples, and instructions.
- Confirm the package supports both first use and later reference.
- Pilot the package with representative users before broader release; record observed task difficulties and revise the affected asset.

## 5. Launch and reinforce

- Publish the assets where the audience already works.
- Provide a clear support path.
- Schedule reinforcement through tips, reminders, practice, or manager follow-up.

## 6. Measure and improve

- Track behavior, work results, questions, errors, and support requests.
- Distinguish participation and satisfaction from demonstrated behavior or work results. Record baseline gaps rather than claiming improvement without comparison.
- Revise, expand, or retire assets based on evidence; identify a maintenance owner and review trigger.
