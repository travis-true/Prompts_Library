# Repurpose one source into training content

**Audience:** Workplace

## Purpose

Turn one approved source into coordinated videos, a channel post, and a quick-reference guide with a shared fact check.

## When to use it

Use this when an approved demo, article, transcript, or set of notes should support several formats.

## Copy-ready prompt

```text
Goal
Turn one approved source into a reusable set of workplace training materials.

Context
Use [AUDIENCE AND DELIVERABLES]. By default, create two short video scripts with distinct learning angles, one channel post, and a concise quick-reference guide.

Source
Base all factual claims and steps on [APPROVED SOURCE MATERIAL]. If the source cannot be opened or is incomplete, identify which excerpt or evidence is needed.

Expectation
Start with a brief source summary and a table of key facts, each with its source location. Draft the requested assets with the same verified steps, terminology, prerequisites, and expected result throughout. Give each asset a specific audience benefit and one relevant next action. Finish with a review checklist for factual consistency, access, and any claims still to verify before release.
```

## Customize before running

- `[AUDIENCE AND DELIVERABLES]` — Who needs the material, where it will be shared, and any changes to the default output bundle.
- `[APPROVED SOURCE MATERIAL]` — Paste the relevant text or supply readable files, links, or timecodes. Include app and audience restrictions where applicable.

## Example output

*Fictional illustrative excerpt.*

Use an approved OneDrive recovery demo to create one clip about finding the correct version, a second about confirming the result, a Teams post pointing employees to practice, and a guide covering the full task.

## Check before using

- Trace key facts, interface labels, and prerequisites across all drafts to the approved source.
- Confirm each format has its own purpose and shares the same expected result.
