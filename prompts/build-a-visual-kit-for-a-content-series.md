# Build a visual kit for a content series

**Audience:** Workplace

## Purpose

Define reusable branding and layout directions for a workplace training series or professional channel.

## When to use it

Use this when launching a series or making its videos and resources visually consistent.

## Copy-ready prompt

```text
Goal
Create a reusable visual kit for [SERIES AND AUDIENCE].

Context
The kit should support recurring workplace content with layouts a trainer or editor can reproduce quickly.

Source
Use [BRAND RULES AND ASSETS]. Keep the established name where one exists. Mark unspecified design choices as proposals.

Expectation
State the series promise in one sentence and write a short series description. For a new series, suggest up to three names with a rationale. Define how to apply color and type, then give layout directions for a title card, cover or thumbnail, demo screen, captions, and end card. For each requested channel, specify what to adapt and which brand elements to carry across. Include contrast, readability, and caption-placement checks. Flag visual choices that need review before use.
```

## Customize before running

- `[SERIES AND AUDIENCE]` — Existing series name, if any, audience, purpose, and distribution channels.
- `[BRAND RULES AND ASSETS]` — Approved colors, fonts, logo rules, example layouts, and output sizes. State any assets still pending.

## Example output

*Fictional illustrative excerpt.*

For a fictional internal ‘One Minute in M365’ series, place the employee task on the opening card, reserve the lower caption area during demos, and use the end card for one approved resource link.

## Check before using

- Compare the kit with approved brand and accessibility requirements.
- Preview one title card, demo frame, and end card at actual delivery size.
