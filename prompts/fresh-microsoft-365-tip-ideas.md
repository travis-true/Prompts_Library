# Fresh Microsoft 365 Tip Ideas

**Audience:** Workplace

## Purpose

Generate five practical Microsoft 365 tip ideas by screening out employee tasks already covered in your Microsoft 365 and Copilot campaigns. Get a 45-minute test for each idea and a ranked shortlist of the two most useful and feasible options.

## When to use it

Use it when planning the next tip for corporate employees and you have recent topics from both campaigns to compare.

## Copy-ready prompt

```text
Goal — Generate fresh ideas for a Microsoft 365 tip that helps employees complete a recurring work task.
Context — The audience is corporate employees using work accounts. I have 45 minutes to test an idea with fictional data.
Source — Use these recent Copilot and Microsoft 365 tip topics as exclusions: [paste titles and the employee task each covered].
Expectation — Give me five ideas. Treat an idea as a duplicate if it solves the same employee problem through essentially the same action, even with a different title, app, or format. For each idea, state the employee problem, what makes it distinct, and how I can test it in 45 minutes. Rank the top two by usefulness and feasibility, and flag the most likely blocker for each.
```

## Customize before running

- Replace the bracketed placeholder with a recent list from both campaigns. Include what the employee was trying to accomplish and the action they practiced.

## Example output

*Fictional illustrative excerpt.*

**Candidate idea** — Help a teammate handle an urgent request while you’re out. This solves a coverage problem and differs from an earlier tip about organizing your own inbox. To test it, build a handoff with three fictional requests and ask a teammate to identify the owner, deadline, and next action for each within the 45-minute test. The likely blocker is that the teammate may lack access to linked files.

## Check before using

- Compare each candidate with both campaigns by employee problem and action.
- Confirm the test fits 45 minutes and works with fictional data.
- Verify any app steps, license requirements, and permissions before scripting the tip.
