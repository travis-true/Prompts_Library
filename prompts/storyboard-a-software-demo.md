# Storyboard a software demo

**Audience:** Workplace

## Purpose

Turn a verified script into a timed shot list with screen captures, readable overlays, and editing cues.

## When to use it

Use this after reviewing a demo script and before recording or editing it.

## Copy-ready prompt

```text
Goal
Turn the approved script into an editor-ready storyboard for a workplace video.

Context
Work within [PRODUCTION SETUP]. Prioritize the viewer’s ability to read the interface and follow the task.

Source
Use [SCRIPT AND AVAILABLE VISUALS]. Preserve the order of verified actions and mark any missing screen capture as a production task.

Expectation
Return a table with start and end time, narration cue, screen action or supporting footage, capture instruction or stock search phrase, overlay text, and editing cue. Use short beats where the action is simple and hold the shot longer for difficult clicks, reading, or verification. Align each visual with the narration. Keep overlays readable and clear of controls and captions. Flag any visual that requires a fresh capture with fictional data.
```

## Customize before running

- `[PRODUCTION SETUP]` — Target runtime, video dimensions, capture tool, caption placement, and any visual constraints.
- `[SCRIPT AND AVAILABLE VISUALS]` — Verified script, approved screen recordings or captures, and any stock asset restrictions.

## Example output

*Fictional illustrative excerpt.*

From 00:12 to 00:18, hold on the version list while the narrator explains how to identify the right draft. Highlight the relevant timestamp, leave room for captions, and cut after the viewer has had time to read it.

## Check before using

- Confirm that every narration beat has a corresponding visual and that time ranges cover the full runtime.
- Preview overlays and captions at delivery size before export.
