# Script a short workplace video

**Audience:** Workplace

## Purpose

Write a concise video script that opens with a real work problem, demonstrates one action, and shows viewers how to verify success.

## When to use it

Use this when you have a verified workplace task for a short screen demo, narrated video, or presenter-led clip.

## Copy-ready prompt

```text
Goal
Write a short video script that helps [TASK AND AUDIENCE] complete one workplace action.

Context
Use [CHANNEL, FORMAT, AND RUNTIME]. Use everyday language and start with a specific work problem or visible outcome.

Source
Use [VERIFIED DEMO NOTES] for facts, interface labels, instructions, and the expected result. Flag missing details for verification.

Expectation
Provide a timed sequence with narration and a matching on-screen action for each beat. Open with an audience-relevant hook, demonstrate the task in a usable order, and close by showing what success looks like. Include one optional next action if the notes support it. Use short, conversational sentences. If the action cannot fit without losing a required step, propose a narrower task or a longer runtime.
```

## Customize before running

- `[TASK AND AUDIENCE]` — What viewers need to accomplish, their experience, and the problem they recognize.
- `[CHANNEL, FORMAT, AND RUNTIME]` — Where the video will appear, who or what will be on screen, and the runtime, such as 30 or 60 seconds.
- `[VERIFIED DEMO NOTES]` — Approved steps, prerequisites, expected result, and an optional follow-up resource.

## Example output

*Fictional illustrative excerpt.*

Open a OneDrive recovery demo with “Saved over the wrong draft?” Show how to identify the intended earlier version in the verified demo, then display the restored contents so viewers can see how to check their own work.

## Check before using

- Read the narration aloud at a natural pace and allow time for screen actions.
- Reproduce the action and confirm the visible success cue before recording.
