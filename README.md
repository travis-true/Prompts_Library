## Start here

1. Choose a resource that matches your workplace task.
2. Replace bracketed placeholders and supply the approved source material.
3. Run the prompt or follow the workflow using tools you have available.
4. Verify the result against your sources and the resource's quality checks.

Prompts are portable text intended for ChatGPT, Microsoft Copilot, Gemini, Claude, and DeepSeek. Tool tags describe intended use, not runtime testing in every product. Paste authorized source text if file access is unavailable. Examples are illustrative, not verified product results.

Skills are instruction-only folders reconstructed from their source guides. Read [using skills](docs/using-skills.md) before enabling one. They supply no missing tools and have not been runtime-tested or installed during this migration.
