## Start here

1. Choose a resource that matches your workplace task.
2. Replace bracketed placeholders and supply the approved source material.
3. Run the prompt or follow the workflow using tools you have available.
4. Verify the result against your sources and the resource's quality checks.

Prompts are portable text intended for ChatGPT, Microsoft Copilot, Gemini, Claude, and DeepSeek. Tool tags describe intended use, not runtime testing in every product. Paste authorized source text if file access is unavailable. Examples are illustrative, not verified product results.

The original 13 skill guides were reconstructed from source pages; 22 additional personal skills include their installed instruction files and supporting resources. Two imported skills include optional Python utilities. Read [using skills](docs/using-skills.md) before enabling one. They supply no missing tools and have not been runtime-tested or installed during this migration.

The upgraded [Live Training Session Design](skills/live-training-session-design/SKILL.md) includes reusable course templates, a corrected 90-minute example with a separate learner handout, critical assessment criteria, and a Python validator. See [upgrade and verification details](docs/live-training-session-design-upgrade.md).

[QA and Release Assets](skills/qa-and-release-assets/SKILL.md) now includes a training-outline review mode, worked example, structural validator and traceable handoff to Live Training Session Design. See [outline-review usage and verification](docs/qa-outline-review-upgrade.md).

[Build Assessments and Evaluations](skills/build-assessments-and-evaluations/SKILL.md) includes the Training Engagement and Assessment Designer’s worked example, consequence clarification, scoring safeguards, fallback-equivalence rules, validator and handoffs. See [usage and verification](docs/assessment-engagement-upgrade.md).

[Live Training Session Design](skills/live-training-session-design/SKILL.md) also includes Live Demo Script Builder 1.1.0 as a specialized scene workflow with state-aware recovery, fallback-equivalence records, worked examples and validation. See [demo usage and verification](docs/live-demo-integration.md).
